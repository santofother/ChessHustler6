# NPC assets (Blender → `public/models/npc/`)

Generated by `tools/blender/npc/build_npc.py` (source of truth; rerun to regenerate). Previews in
`docs/models/npc/` (`preview_lineup.png`, `preview_clips.png`, `preview_<variant>.png`).

```
blender --background --factory-startup --python tools/blender/npc/build_npc.py          # everything (~5 min)
blender ... build_npc.py -- --anims-only --no-previews                                   # just npc_anims.glb
blender ... build_npc.py -- floral_guy bodyguard                                         # subset of variants
node tools/blender/npc/check_glb.mjs                                                     # three.js validation
```

Each variant GLB = armature `NPC_<variant>` + ONE skinned mesh (all primitives share one skin) + a small
`PROP_PHONE` mesh parented to bone `hand_R` (hide it unless the NPC is on its phone). No clips inside the
variants — load the clips once from `npc_anims.glb`.

## Conventions
- Native height **1.78–1.84 m** (hats), metres, +Y up, **faces −Z**, origin between the feet on the floor.
  Game scale for NPCs next to the board ≈ 0.7–0.8.
- Body types: `m` = floral_guy, hoodie_guy, dock_worker, bodyguard, beach_guy, rich_old; `f` = tank_woman,
  party_woman. All variants share the **identical** skeleton rest pose, so every clip works on every variant.

## Skeleton (17 bones, identical names in all files)
`hips` (root; only bone with a translation track) › `spine` › `chest` › `neck` › `head`;
`chest` › `upperarm_L|R` › `lowerarm_L|R` › `hand_L|R`; `hips` › `upperleg_L|R` › `lowerleg_L|R` › `foot_L|R`.
`_L` = character's left. No dots in names (three's PropertyBinding never renames them).
Hand bone local frame (for attaching props): origin = wrist, **+Y toward the fingertips, −X = palm side,
+Z = thumb/forward** (R hand).

## Materials (recolour per instance)
`TINT_Top`, `TINT_Bottom`, `TINT_Skin`, `TINT_Hair`, `TINT_Shoes`, `TINT_Accent` (hats, hair ties, belts,
ties, gloves, floral print, stripes…) — present in every variant. Fixed: `EYE`, `MOUTH`/`LIP`, `LENS`,
`SHIRT_WHITE`, `SHOE_WHITE`, `GOLD`, `CHROME`, `BLACK`, `LEATHER`, `HIVIS`, `REFLECT`, `PRINT_B`, `DARK_GREY`.
(`NpcAssets.roleFor` maps these names already; the old upper-case names are gone.)

| `Sit_Ground` | 4.0 | on sand/floor, knees up, leaning back on both hands |

| `Wave` | 2.0 | right hand waving |
| `WaveFlag` | 1.6 | right arm high sweeping side to side — attach `Flag` to `hand_R` |

glTF animation extras come through as `clip.userData`: `{ loop: true|false }`, and `speed` on `Walk`.
Legs were solved with IK before baking, so planted feet don't slide in any standing clip.

## Held props (`npc_props.glb`)
Nodes `Phone`, `Cup`, `Bottle`, `Flag`. Each node's origin = the `hand_R` bone origin and its geometry is
already placed in the palm, so attach with an identity transform: `handR.add(prop.clone())` (no rotation
flip). Cup/Bottle stand upright in the `Drink` pose; the flag pole runs up out of the fist in `WaveFlag`.

## three.js usage
```js
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import * as SkeletonUtils from 'three/addons/utils/SkeletonUtils.js';
const [anims, guy] = await Promise.all(['npc_anims', 'floral_guy'].map((n) => loader.loadAsync(`models/npc/${n}.glb`)));
const clips = Object.fromEntries(anims.animations.map((c) => [c.name, c]));
const npc = SkeletonUtils.clone(guy.scene);           // one per NPC
npc.getObjectByName('PROP_PHONE').visible = false;
const mixer = new THREE.AnimationMixer(npc);
const a = mixer.clipAction(clips.Talk);
a.time = Math.random() * clips.Talk.duration; a.play();
// one-shot: mixer.clipAction(clips.Cheer_Once).setLoop(THREE.LoopOnce).clampWhenFinished = true
// per frame: mixer.update(dt)
```

`SkeletonUtils`, checks the 17 bones / 6 TINT materials / PROP_PHONE on `hand_R`, that every clip exists,
has tracks that all bind to variant bones, loops seamlessly, and actually moves `hand_R` through an
`AnimationMixer`, plus the props nodes. Last run: **ALL NPC CHECKS PASSED**.

## Known limits
- Skirt (party_woman) is weighted half to the thighs: fine for walk/dance, the legs poke through a little in `Sit`.
- Mitten hands (no fingers): `Point` reads from the arm, not a finger.
- Bone rolls are Blender's; don't author new clips in three.js with assumed local axes — use these clips.
